# Posting kit: 30 days on Buffer

Generated from `tools/video/kit/kit.js` by `build-kit.js`. Edit kit.js and
re-run it rather than editing this file. The same calendar, with copy buttons,
is `posting-kit.html` in `Downloads/PomoMons-shorts/`.

Free Buffer plan: 3 channels, 10 queued posts per channel. Loading 7 a week
stays under that. Reddit isn't in Buffer; it's posted by hand (see
launch-posts.md and seo-audit-2026-10-31.md).

## Set up once
1. **Sign up.** Make a free account at buffer.com. Set your time zone in Settings first.
2. **Connect 3 channels.** TikTok, Instagram and YouTube. Instagram has to be a free Creator or Business account; Buffer walks you through switching if needed.
3. **Set one daily time.** In the posting schedule, add one time slot, every day, for all 3 channels. Suggested: 6:00 PM US Eastern (convert to your time zone). The same time every day matters more than which time.
4. **Every Sunday, load the week.** For each day, in order: new post, tick all 3 channels, upload the video, turn on the option to write different text per channel, paste the 4 fields below (Instagram: choose Reel; YouTube: Short, "not made for kids"), then Add to Queue. 7 posts per channel stays under the free cap of 10.
5. **When each post goes live.** Pin the suggested comment, then reply to every comment for the first hour or two. This matters more than anything else on this page.
6. **Sunday review.** Note the 3 videos with the most views. Ask Claude for more videos like those.

4. End screen: the last 15 seconds are an end card, so add a Subscribe element and the other long video there.
5. Then, on each Short already posted, set the 1-hour video as its Related video, so Shorts viewers can tap through to it.
6. Make a playlist called "Study With Me" with both videos in it.
